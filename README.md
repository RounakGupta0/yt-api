# yt-api

A backend REST API for a YouTube-like video sharing platform built using Node.js, Express, MongoDB, and Cloudinary.

## Features

- User Authentication (JWT based)
- Video upload and management
- Comment system
- Like / Unlike videos
- Like / Unlike comments
- Subscribe / Unsubscribe channels
- View count tracking
- Protected routes

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
- Cloudinary
